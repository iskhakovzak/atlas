# Atlas — выбор дизайн-направления

Статус: направление A / Commerce выбрано владельцем 24 сентября 2026. Первые визуальные проходы перенесены на реальные страницы в `app/atlas-design.css`, `app/experience.css` и мобильную админку. Остальные варианты сохранены для сравнения. Гостевая главная теперь использует фотографию из существующих ассетов, а создание подборки и ответ клиенту открываются в формах.

## Просмотр

Из корня проекта: `node design/serve.mjs`, затем открыть http://127.0.0.1:4318/.
Сервер доступен только на этом компьютере, отдаёт только явно разрешённые файлы. Нет подключения к API, авторизации, каталогу или платежам. Не вводите персональные данные.

- A / Commerce — спокойная сетка, выразительный navy, лайм только для акцента. Рекомендуемая универсальная основа.
- B / Editorial — редакционная типографика, крупнее фото, прямые края. Более характерная подача одежды.
- C / Atlas refined — знакомые голубые поверхности, синие действия и округления, более консервативное развитие.

У всех вариантов одинаковые четыре экрана: каталог, товар, оформление, кабинет. Есть RU/UZ/EN, мобильный просмотр, пустое состояние, ошибка и загрузка. Выбор размера, добавление в пример корзины, согласие, поиск и раскрытие разделов работают локально. Фото взяты из проекта; цены, размеры, адреса и статусы исключительно образцы. Это не новый калькулятор коммерческих тарифов.

Возможен выбор B для каталога и A для рабочих сценариев, но тогда общие токены и компоненты должны оставаться одними.

## Мобильное приложение — концепция

Откройте `http://127.0.0.1:4318/mobile.html` после запуска preview-сервера. Отдельный прототип показывает 24 клиентских экрана для общей концепции iOS/Android: самостоятельный вход, каталог, карточку товара, импорт, оформление, заказы, профиль, документы и справочные разделы. На широком экране рядом доступен список переходов; на телефоне он расположен под макетом. Переходы по карточкам доступны мышью и клавиатурой. Используются только локальные проектные изображения и вымышленные данные. Формы, цены, авторизация, баланс, заказы, документы и сообщения не подключены к API и не сохраняются. Это обзор интерфейса, не Expo-приложение и не коммерческое предложение.

## Кандидат дизайн-системы

Токены прототипа в `screen.css`, не подключены к production. База: navy #142344, blue #193dcf, lime #dcfb78. Основной текст 16 px, подписи 14 px, метаданные 12 px; заголовки используют отдельную адаптивную шкалу. Отступы 4/8/12/16/24/32/48/64. Семантические роли: заголовок страницы, заголовок секции, название товара, цена, основной текст, поле, подсказка. Общая палитра не означает одинаковый размер текста.

После выбора: закрепить единственный набор production-токенов, мигрировать по семействам экранов, удалять только доказанно заменённые правила. Не добавлять седьмой глобальный слой переопределений.

## Очередь переноса

1. Shell, каталог, избранное: навигация гостя/клиента, поиск, реальные товарные фото, основная цена.
2. Импорт и batch-import: сохранение формы при смене языка, варианты, устаревшие данные, безопасная ручная помощь.
3. Корзина и оформление: получатель → проверка; согласия и изменения цены видимы; существующие серверные расчёты неизменны.
4. Кабинет, заказы, баланс: один следующий шаг, понятные статусы, история согласований.
5. Уведомления, паспорт, документы, декларация, адреса и поддержка: пустые/ошибочные/заполненные состояния, локализация.
6. Админка, операции и аналитика: плотность данных отдельно от витрины, роли и мобильные действия.
7. Таможня и legal: короткие вводные, доступные полные условия, без обещаний гарантированных платежей.

Каждый этап: 1440/800/390/360 px, RU/UZ/EN, клавиатура и видимый focus, контраст, длинные строки, загрузка/ошибка/пусто, ограничения ролей. Полная production-проверка после десяти существенных итераций и перед пилотом; целевые проверки по ходу.

## Проверка прототипов

`node design/check.mjs` использует установленный Playwright. При необходимости задайте `ATLAS_PLAYWRIGHT_MODULE` (имя пакета или file URL) и `ATLAS_CHROME` (путь браузера). Предварительно запустите preview-сервер. Проверка охватывает 144 комбинации темы/экрана/языка/ширины, загрузку картинок и базовые взаимодействия; снимки сохраняются в игнорируемый `outputs/design-review`.

Автоматическая проверка геометрии не заменяет экспертную оценку контраста, screen reader и пользовательское исследование. Реальная авторизация, операторские страницы и серверное сохранение этим прототипом не проверяются.
