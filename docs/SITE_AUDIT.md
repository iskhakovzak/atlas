# Аудит действующего Atlas

Базовая версия на VPS: `b209d2077a59fa4b6eea0015932a071ee747bd74` (PR #130), совпадала с GitHub main перед началом проверки. Работа выполнена в отдельной копии; незавершённые изменения основной папки не включались.

## Исправления

1. Язык на странице с `?lang=ru` после выбора English откатывался при обновлении. Явный параметр языка теперь обновляется вместе с настройкой устройства; остальные параметры и фрагмент сохраняются.
2. Ссылки смены языка в меню и подвале теряли URL товара, фильтры и `return_to`. Теперь сохраняют полный адрес страницы, а Ctrl/Cmd/Shift/Alt-клики работают как обычные ссылки.
3. Уже вошедший посетитель при SPA-переходе на страницу входа мог попасть на главную раньше разбора `return_to`. Перенаправление ждёт готовности адреса возврата. Проверка безопасного пути остаётся прежней.
4. При сбое или одновременных запросах заказ с промокодом мог разойтись с учётом скидки. Теперь заказ, запись скидки и счётчик сохраняются в одной транзакции. Если условия скидки изменились во время оформления, сервер просит пересчитать её. Повтор уже выполненного запроса возвращает сохранённый заказ. Если после отмены заказа пришлось восстанавливать использование промокода, новая проверка сразу учитывает освободившееся место.
5. На узкой корзине длинная расцветка скрывала размер в конце строки. Текст варианта теперь переносится и показывает цвет и размер целиком.
6. На экранах до 380 px карточка cookies занимает меньше места. Текст, документы и все способы выбора доступны без декоративной иконки и лишних отступов.

## Проведённые проверки

- 29 основных адресов: публичные страницы открылись, личные API без сессии вернули 401, неизвестный URL — 404.
- Дополнительно проверены доставка, документы и начало оформления. Выдуманный адрес `/account/recipients` вернул ожидаемый 404; найденных ссылок на него нет, ошибкой сайта он не считался.
- 65 найденных внутренних ссылок без ошибок; 152 файла JS/CSS/шрифтов/других ресурсов — без ошибок.
- Chrome на компьютере и эмуляция телефонов на 320 и 440 px. Для Safari/WebKit на физическом iPhone нужна отдельная проверка.
- Главная, мобильный каталог, карточка товара, смена цвета/фото/размера, уведомления, заполненная и пустая корзина.
- Добавление тестового варианта из каталога: магазин вернул актуальную цену вместо старой, расчёт обновился; после повторного подтверждения товар попал в корзину. Только добавленная тестовая позиция удалена, корзина восстановлена пустой. Оплата и размещение заказа не выполнялись. Существующие заказы, документы и настройки не изменялись.
- Тесты на SQLite-адаптере VPS покрывают откат при ошибке записи, конкурентные запросы, изменение условий оператором, последнее доступное использование и восстановление счётчика после отмены.

## Границы и дальнейшая работа

Нельзя считать доказанной исправность всех 215 магазинов и всех вариантов сети, реальных платежей, физической доставки, нативных приложений и физического Safari. Проверка не включает изменение производственных реквизитов/документов или создание реального заказа. На страницах не найдено основания для массового редизайна: приоритет отдан воспроизводимым ошибкам.

## Наличие товаров после выкладки

Обновление интерфейса после PR #131 прошло на VPS. Повторная проверка охватила 18 публичных маршрутов, пять личных API и 166 статических ресурсов. В каталоге было 510 карточек, все со ссылками eBay. Четыре выборочно проверенные карточки загрузили ответ eBay об отсутствии товара, но оставались на витрине. Импорт adidas KI9681 вернул цену 42 USD, 11 фотографий и один доступный вариант.

Исправление отличает подтверждённое отсутствие от сбоя магазина. Карточка скрывается с сохранением черновика. Планировщик VPS проверяет просроченные карточки по мере наступления срока проверки, поэтому оценить весь каталог можно после накопления результатов.
